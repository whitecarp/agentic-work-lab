# 逐幀修復與驗證

**繁體中文** · [English](temporal-quality_EN.md)

案例：GPT 值班日記 05 · v3-antiflash · 2026-10-28

## 問題與修正

畫面在淡入前突然完整出現、右側內容替換時閃白，以及影片入口殘留前一鏡頭，會讓教學難以跟讀。本次修正隱藏初始狀態、將動畫邊界對齊影格、整體替換右側內容區，並在一處入口保留四幀乾淨畫面。沿用 v2 音訊母帶，讓視覺修復不改動已確認的配音。

| 檢查 | 紀錄結果 |
| --- | --- |
| 成片 | 434.47 s · 1920 × 1080 · 30 fps · H.264/AAC |
| 掃描覆蓋 | 13,034／13,034 幀；以 320 × 180 解析度分析 |
| 已知缺陷 | 複核 11 組修正前後片段，回報已修復 |
| 指定脈衝候選 | 孤立 ABA、提前對比峰值、黑色脈衝及右側白色脈衝均為 0 |
| 影片入口 | 複核 12 處入口，72 個入口影格與來源比對 |
| 音訊 | 沿用 v2 音訊母帶；對齊偏移 0 ms；−15.97 LUFS、−2.21 dBTP |

掃描仍找出一個短暫變化事件，來源比對確認是原頁面正常更新；另有 17 處刻意保留的左側換章空隙。這些分類防止把所有變化都當成錯誤。技術檢查與指定畫面複核通過，不等於人工以正常速度逐字看完、聽完整片，也不是光敏安全認證。

## 可複用的問題修復方法

先把「看起來不對」轉成具體錯誤、時間點與驗收條件；局部修復後保留未改動部分，再用同一套指標比對。資料整理、文件和內容製作也可採用相同習慣：鎖定來源、標出錯誤欄位、檢查修正，並讓同事知道哪些內容尚未核實。

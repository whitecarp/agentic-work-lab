# 工具與插件選型

**繁體中文** · [English](toolchain_EN.md)

此表記錄本專案實際可見的工具與使用證據，不把「已安裝」寫成「已精通」。

| 工具 | 實際用途 | 證據與版本 |
| --- | --- | --- |
| ChatGPT／Codex | 對話拆解需求、研究、編輯程式與整理交付。 | 本倉庫程式、文件、提交與製作紀錄。 |
| DeepSeek 獨立營運實例 | 接手週期性營運與共享進度。 | [實際排程紀錄](automation-verification.md)；不是同題模型能力跑分。 |
| GitHub 插件 | 讀回倉庫、提交文件、驗證遠端版本。 | 本倉庫的提交與檔案。 |
| Bili CLI skill + CLI | 取得稿件清單、創作中心數據、發布回讀。 | 此次 CLI 回報 **0.7.0**；[資料集](../data/README.md)。 |
| Breeze CLI／Audio Studio | 語音、選用聲段與混音工作流。 | 兩個可編輯交付案例；未把未確認的 CLI 版本填成數字。 |
| HyperFrames + GSAP | 以 HTML 場景與時間軸組合影片。 | 案例固定 **HyperFrames 0.8.208**；本地 GSAP 依賴。 |
| Seedance | 影片生成與教學實驗。 | GPT 第三期製作版本與第四、五期教學。 |
| FFmpeg／ffprobe | 媒體格式、解碼、混音與編碼檢查。 | 製作交付中的技術檢查紀錄。 |
| Node.js／JavaScript | 資料整理、示例流程、雜湊核對、測試。 | 此次環境 **Node.js 26.11.1**；公開腳本只用標準函式庫。 |
| Python／PowerShell | 原專案發布控制、資料採集與驗證腳本。 | [程式導覽](code-map.md)。 |
| Git | 本地與遠端版本管理。 | 此次環境 **2.53.0.windows.3**。 |

Computer Use 用於原生接口未涵蓋的網頁操作；先使用連接器或 CLI，再以瀏覽器補足。插件和 skill 是工作流入口，並不等於自行訓練了模型。

目前沒有 GitHub Copilot 或 Microsoft Copilot 的實作證據，因此不將它們列為已完成案例。

# 可編輯影片交付

**繁體中文** · [English](editable-video-workflow_EN.md)

整理日期：**2026-10-28**

## 工作流程

1. **先鎖定台詞與聲音。** 保存選用的原始聲段，依實際音訊時長安排畫面。
2. **場景、字幕、混音共用時間軸。** 標示全片時間與場景內時間，避免片段重用時錯位。
3. **記錄已烘焙的混音。** 若音訊已包含音量與效果，重開工程時避免再次套用。
4. **固定工具與依賴。** 交付版本使用固定的 HyperFrames 版本與本地依賴；重開時先檢查、再預覽、最後渲染。
5. **以實際輸出檔驗收。** 記錄解碼結果、畫面抽查、聲音檢查、人類審片與 SHA-256。

## 兩個實例

| 項目 | 鯨魚娘 02 | 鯨魚娘 03 |
| --- | ---: | ---: |
| 時長 | 116.7 s | 188.8 s |
| 畫面 | 1920 × 1080, 30 fps | 1920 × 1080, 30 fps |
| 總幀數 | 3,501 | 5,664 |
| 已混音元件 | 38 | 47 |
| 選用原始聲段 | 13 | 28 |

02 的第三版修正了第五場的 AI 聲明紅圈。03 的正式交付檔與人類接受的完整有聲預覽逐位元組一致，複製後以雜湊核對。

03 的完整解碼與指定畫面抽查通過；工具檢查的 lint/runtime/layout 錯誤為零，但仍有提示與資訊。代理未以正常速度連續觀看或親耳聽完整片，因此不把機器檢查等同於人工逐字驗收。

## 可重用的交付資訊

使用[交付清單](../templates/delivery-manifest.json)記錄檔名、雜湊、媒體格式、依賴版本、審片方式、未解決問題與發布狀態。未完成的檢查使用 `null` 或 `not_run`，不預填成功。

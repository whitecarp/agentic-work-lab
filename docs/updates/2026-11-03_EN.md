## Measure the wait before choosing an optimisation

The Instagram publication command took **412.217 seconds (about 6 minutes 52 seconds)**. The wait from Share to platform confirmation was **380.551 seconds, about 92%**. That period includes transfer, processing and confirmation; the measurements cannot separate them, identify a network cause or establish average platform speed.

| Phase | Seconds |
|---|---:|
| Source and plan checks, outside publication command | 0.438 |
| Local rehearsal, outside publication command | 0.444 |
| Sign-in preflight and close, outside publication command | 10.137 |
| Publication command: browser start to file entry | 11.058 |
| Publication command: wait after submission | 380.551 |
| Publication command: independent read-back | 5.224 |

This is one observation. The table selects major phases rather than an exhaustive additive breakdown. There was no retry or second Share. Follow-up work should make the waiting phase understandable and measure whether publishing to different platforms concurrently actually reduces total time. No live concurrent-publication speedup has been measured yet.

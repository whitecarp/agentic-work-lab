- **Full Integration of Two Open-Source Tool Suites under [`tools/`](../../docs/code-map_EN.md)**:

     - **Core Purpose**: Persistent local working-memory, full-transcript archiving, and post-compaction recovery system across Claude Code, OpenAI Codex, Google Antigravity, and OpenClaw (shipping a zero-dependency `amk` CLI hook suite and a static web console under [`web/`](../../tools/ai-memory-keeper/web/README_EN.md)), plus Claude model-tier verification and dual credential routing (Google AI Studio API key + locally signed Google Cloud Service Account `.json` token).

# Security and privacy

Do not include API keys, passwords, account files, browser profile backups, private conversations, selected text, or screenshots containing those items in issues.

For a sensitive report, contact the repository owner through a private contact channel they have made available. If none is available, open an issue requesting a private channel without disclosing exploit details or private data.

Downloads in the preview release are unsigned. SHA256SUMS.txt identifies the exact published files; it does not substitute for code signing.

## 中文

预览版未做代码签名。SHA256SUMS.txt 用于核对已发布文件，并不等于数字签名。

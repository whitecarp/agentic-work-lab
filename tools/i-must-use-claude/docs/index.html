核对文件Verify the files

本轮仍是未签名预览版，Windows 可能提示“已保护你的电脑”；详见代码签名政策与当前状态。先在 PowerShell 运行 Get-FileHash 文件名 -Algorithm SHA256，与本版 SHA-256 对比。哈希只验证文件完整性，不认证发布者身份；确认来源和哈希后，再决定是否点「更多信息 → 仍要运行」。

This remains an unsigned preview; Windows SmartScreen may block the first launch. Read the code-signing policy and current status. Run Get-FileHash <file> -Algorithm SHA256 and compare with this release's SHA-256. A hash verifies integrity, not publisher identity. After checking source and hash, decide whether to choose More info → Run anyway.

# 教學影片提綱 / Tutorial brief

參考節奏：[酷可 mc 的 bili-cli 介紹](https://www.bilibili.com/video/BV1bwnF6eEe8/)。只借鑑「需求→工具→真實操作→成果」敘事，不重用原片、台詞或角色表演。 / Reference the need→tool→operation→result structure, without reusing footage, wording or character performance.

1. **需求 / Need:** 一支自己的原創影片，要分送不同平台；每站登入與欄位不同。 / One original video, several platforms with different login and metadata.
2. **選擇 / Choice:** 展示 B站、YouTube、抖音、Instagram、X 清單，觀眾選一個或幾個；TikTok 暫停理由及測試協助入口另外說明。 / Choose Bilibili, YouTube, Douyin, Instagram or X; explain TikTok suspension and the volunteer testing link separately.
3. **登入 / Sign-in:** 在內置瀏覽器打開官方頁，觀眾自己選登入方式。畫面遮住信箱、電話、驗證碼；不要錄製完整登入過程或 QR。 / Open official pages, let viewers choose the method; omit credential entry and QR codes from the recording.
4. **方案 / Plan:** 展示同片不同標題、caption、AI 聲明及可見範圍，依首次選擇自動處理或審閱。 / Apply platform-specific text/disclosures/audience under the chosen automatic or review policy.
5. **實證 / Evidence:** 只展示已實際完成的上傳與對應作品連結；未驗證的平台直接標示。 / Show only real completed uploads and matching work links; label unverified platforms.
6. **交接 / Handoff:** 展示 JSON 回執及去重：同影片再次執行不會再投稿。 / Show receipts and duplicate suppression.
7. **開源 / Open source:** 給出 GitHub 工具入口、版本與能力矩陣。不要宣稱「五站全功能」或虛構提效數字。 / Link the tool, version and capability matrix; do not claim full five-platform support or invented efficiency gains.

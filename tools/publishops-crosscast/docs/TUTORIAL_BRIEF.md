# 教學影片提綱

**繁體中文** · [English](TUTORIAL_BRIEF_EN.md)

參考節奏：[酷可 mc 的 bili-cli 介紹](https://www.bilibili.com/video/BV1bwnF6eEe8/)。只借鑑「需求→工具→真實操作→成果」敘事，不重用原片、台詞或角色表演。

1. **需求** 一支自己的原創影片，要分送不同平台；每站登入與欄位不同。
2. **選擇** 展示 B站、YouTube、抖音、Instagram、X 清單，觀眾選一個或幾個；TikTok 暫停理由及測試協助入口另外說明。
3. **登入** 在內置瀏覽器打開官方頁，觀眾自己選登入方式。畫面遮住信箱、電話、驗證碼；不要錄製完整登入過程或 QR。
4. **方案** 展示同片不同標題、caption、AI 聲明及可見範圍，依首次選擇自動處理或審閱。
5. **實證** 只展示已實際完成的上傳與對應作品連結；未驗證的平台直接標示。
6. **交接** 展示 JSON 回執及去重：同影片再次執行不會再投稿。
7. **開源** 給出 GitHub 工具入口、版本與能力矩陣。不要宣稱「五站全功能」或虛構提效數字。

目前可展示已驗收的 YouTube 私密上傳流程；抖音現有私密作品修改仍在審核，其餘平台依驗證記錄標示。拍攝時標明私享狀態，不能宣稱全部平台已實發成功。

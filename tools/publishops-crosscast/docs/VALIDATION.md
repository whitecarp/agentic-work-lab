## 0.4.1：修復抖音回覆與讀回

使用者在手機確認只有原留言。公開作品頁的發送請求沒有產生可讀回的回覆；改為創作者中心的指定留言回覆框，避免誤用頁面頂部的新增留言框。後台新鮮回傳確認原留言回覆數為 0 後，進行有記錄的修復測試，沒有再次建立頂層測試留言。

**已成功回覆並由獨立 CLI 會話讀回。** 新評論 ID、作者、原文「你好」和巢狀父留言皆匹配；另以官方頁自行載入的評論資料交叉核對。修復前的失敗回執保留。影片、簡介、封面、可見性及排期未改動。不是僅憑 HTTP 200 或點擊結果判定成功。

同時修正抖音缺少絕對時間時的核驗錯誤，辨識子評論的父留言，並區分平台拒絕、發送未確認與可見性核驗。回覆目標與創作者中心可見列不能唯一對應時停止；目前只支援回覆頂層留言。沒有新增自動重送機制；本次是使用者回報與新鮮後台資料支持的受控修復。

**147 項測試通過。** 新增同作品／父留言／作者／文字核對、空回執與拒絕、不覆蓋修復歷史、巢狀 DOM 與無絕對時間回歸。五站自測留言與回覆均已讀回；這是開發期實測，不能外推為所有帳號、頁面或乾淨安裝的完整無人值守驗收。

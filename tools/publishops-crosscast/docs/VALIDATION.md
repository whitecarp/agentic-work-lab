## 0.2.5 最新狀態

**2026-10-29 YouTube API 連線實測：** 桌面 OAuth 授權完成，`vpub auth status youtube --method api` 已回傳正確頻道；API 讀回既有測試影片的公開狀態與處理完成狀態。缺少 PySocks 時，`httplib2` 忽略代理並逾時；補上 `PySocks==1.7.1` 後恢復正常，已納入安裝依賴及 `doctor` 檢查。本次只做讀取，未新增上傳或修改平台內容；真實 API 上傳、封面寫入及播放列表寫入仍待驗收。

使用者提供兩段手機錄屏並回報：一秒片頭沒有解決需求，手機可從相機膠卷選直式封面。已抽查錄屏中的編輯封面及返回作品畫面；這不是 Agent 控制手機或全程播放驗收。撤回片頭功能，原影片發布與抖音共用圖片交接已實作；本輪沒有為更新規則重新發布測試片。

72 項測試通過；目前新增的四項測試核對原影片 SHA-256 不變、精確重用抖音直式圖、方案隔離／去重、覆蓋防護及無圖片時不偽造手機成功。0.2.4 的 FFmpeg 實驗測試屬歷史記錄，不代表該功能仍在使用。

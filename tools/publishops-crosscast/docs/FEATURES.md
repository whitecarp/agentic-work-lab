# 功能範圍

**繁體中文** · [English](FEATURES_EN.md)

**X 發布僅面向已訂閱、且帳號實際能進入 Media Studio 的使用者。** 目前不提供免費帳號發布路徑；登入或付款本身不代表已具備發布權限，上傳前仍會核對媒體庫入口與所選帳號。

**0.3.2 alpha。** 新方案在首次登入後由 CLI 執行；`method: native` 是明確選用的宿主瀏覽器備援。B站繼續呼叫 [bili-cli](https://github.com/kukemc/bili-cli)。

| 能力 | Bilibili | YouTube | 抖音 | X | Instagram |
|---|---|---|---|---|---|
| 登入 | 上游 CLI | 桌面 OAuth | 專用官方 Chrome | 專用官方 Chrome | 專用官方 Chrome |
| 預設發布 | bili-cli | 官方 API | 背景瀏覽器 | 背景 Media Studio | 背景瀏覽器 |
| 封面 | 上游功能 | 封面 API | 橫式＋直式 | Studio 自訂縮圖 | 獨立圖片；原片比例 |
| 目標文案語言 | 簡體中文 | 英文 | 簡體中文 | 英文 | 英文 |
| 作品回讀 | 上游功能 | API | 創作者卡片／詳情 ID | 自己主頁／帖文 | 自己主頁／Reel |
| 完整歷史／數據／評論 | 上游功能 | 未統一 | 未統一 | 未統一 | 未統一 |

共用能力：確切來源方案、逐平台帳號核對、不可變上傳快照、本機回執，以及最終提交後不盲目重試。瀏覽器 `works` 只讀可見首頁（抖音最多十張卡片）；尚無詳情 ID 的審核中作品保留待驗狀態。

第二期真實上傳及開發限制見[驗證記錄](VALIDATION.md)。背景瀏覽器不是官方直連 API，也沒有速度保證；介面變更、登入過期及驗證可能需要介入。文案寫作／翻譯由宿主聊天模型透過 request/apply 完成，不會翻譯影片本身。

內容語言與平台目標不同時保留原語言＋翻譯；中文的簡繁體在 B站／抖音統一簡體，不重複兩段。抖音自訂章節已接入 CLI 發布／驗證流程。`vpub edit` 支援 YouTube 資料、Instagram 配文、可用的 X 編輯入口及抖音封面／章節；native 交接仍保留。共用直圖位元組一致，但底部小字在兩站手機網格被裁切，版式尚未驗收。郵件僅支援 Gmail、預設關閉，使用者主動要求時才協助安裝／連接插件並開啟。Outlook、QQ、網易及 SMTP 均不支援。TikTok、通用互動指令及 YouTube 卡片／可點擊片尾未實作。

## 歷史變更

## 0.2.0：跨平台內容設定

| 能力 | 本版範圍 |
| --- | --- |
| 文案生成 | 宿主模型 request/apply 與來源校驗；沒有獨立模型 API |
| 語言 | B站／抖音為簡體中文，YouTube／Instagram／X 為英文；雙語需明確選擇 |
| 封面 | 製作封面轉為平台畫布，保留完整圖；不可變快照與逐版讀回 |
| 現有作品修改 | 修改文案／封面保留原作品 ID；縮小受眾後以實際讀回確認 |
| 播放列表 | YouTube 內置瀏覽器欄位與選配 API 成員操作；B站合集沿用上游 |
| 郵件 | 預設關閉；宿主 Gmail／Outlook 寄信交接、領取與持久結果；無簡訊 |
| 章節 | 內置瀏覽器交接；抖音章節已提交，使用者確認手機可見 |

詳見 [README](../README.md) 與當前 [驗證記錄](VALIDATION.md)，上方早期能力表中的發布驗收以此記錄為準。

## 0.2.2：草稿與明確發布

Instagram／X 可用 `init --draft-only`，區分預覽與保存草稿；使用者明確改為發布後才用 `browser authorize-publish` 繼續同一份內容，不重傳。X 的草稿及原帖已實測，Instagram 首次提交失敗，重新登入及核對無重複後重試成功；封面網格裁切仍待適配。

## 0.2.3：刪除回執與封面限制

Instagram 新增明確刪除交接、確認結果與刷新後缺席證據、保留歷史的同片封面重發流程。已實測刪除；替換影片尚未分享。X 自訂封面改走需要訂閱權限的 Media Studio；本次媒體庫初始化失敗，封面修改未驗收。

## 0.2.4 歷史實驗：片頭方案已撤回

當時的 `instagram prepare` 自動判斷：橫式加入 1 秒原封面，直式／方形原片通過；維持原比例、原檔、可追溯雜湊及重跑復用。X 原橫式封面已透過 Studio 保存及發布；這是宿主網頁操作，不是新建了獨立 API。前面的 0.2.3 段落是歷史測試狀態，以最新 [驗證記錄](VALIDATION.md) 為準。

## 0.2.5：原影片與共用直式封面

依手機實測撤回一秒片頭處理，刪除該命令。Instagram 準備不改影片位元組、比例或時長；網頁另傳封面，手機從相機膠卷選抖音共用圖。交接回傳同一張圖片的路徑與雜湊，手機保存由使用者操作並驗收。

# Operations checklist

[繁體中文](operations-checklist.md) · **English**

- [ ] Confirm the sole operator and latest user instructions.
- [ ] Read stop conditions, prior results, and due times.
- [ ] Execute only due, authorized work.
- [ ] Check whether an action already succeeded before writing again.
- [ ] Record success from read-back evidence and retain failure reasons.
- [ ] Separate trigger, start, completion, and platform-action states.
- [ ] Update due times and stay quiet when nothing changes.

This is a process template; it does not implement a scheduler or authentication.
